# Gender-disparities-in-workforce-participation-and-remuneration

## Overview

This project analyses gender equality trends across multiple countries using a dataset containing social and economic indicators from 1976 to 2021. The analysis focuses on differences between males and females in areas such as age at first marriage, labour force participation, wage and salaried employment, and employment across agriculture, industry, and service sectors. The aim of the project is to identify patterns, disparities and changes in workforce participation and remuneration between genders over time.

## How the Program Works

The project was created in R using the tidyverse collection of packages for data cleaning, transformation, and visualisation. The dataset was first cleaned and reshaped using functions such as pivot_longer(), mutate(), and drop_na() to organise the data into a more usable format and remove missing values. The data was then filtered and grouped to answer specific research questions. Summary statistics were calculated and a series of visualisations were created using ggplot2, including line graphs and bar charts. These visualisations were used to compare gender differences in marriage age, labour force participation, employment sectors, and wage and salaried employment, allowing key trends and insights to be identified and reported.
